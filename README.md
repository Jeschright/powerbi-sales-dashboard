# Project Title: Sales Performance Dashboard

## 📊 Overview
This Power BI report analyzes sales performance across regions, products, and time periods. It highlights trends, identifies growth opportunities, and provides actionable insights for leadership.

## 🎯 Key Features
- KPI cards for revenue, profit, and YoY growth
- Dynamic date filtering
- Region and product drilldowns
- DAX measures for margin, YoY, and running totals
- Clean, executive-friendly layout

## 🧠 Skills Demonstrated
- Data modeling (star schema)
- DAX calculations
- Power Query transformations
- Visualization best practices
- SQL for data preparation (if applicable)
